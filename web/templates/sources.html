Push API reference

Send one record (JSON object), a batch (JSON array) or newline-delimited JSON. Fields use NSL-KDD names; missing fields get typical defaults. Add src_ip and label if you have them.

curl -X POST {{ ingest_url }} \ -H "X-API-Key: <your key>" -H "Content-Type: application/json" \ -d '{"src_ip":"10.0.4.7","protocol_type":"tcp","service":"http","flag":"SF","src_bytes":215,"dst_bytes":45076,"count":1,"srv_count":1}' # or stream a whole log file one record at a time with the bundled agent: python agent/send_logs.py my_traffic.csv --url {{ ingest_url }} --key <your key> --rate 5
